# /design: Claude Design reference (read-only)

Source: Claude Design project `3f12181e-90f3-4993-8c1f-fcfdcdd14011`, file **Pocket Sports Design.dc.html**
(https://claude.ai/design/p/3f12181e-90f3-4993-8c1f-fcfdcdd14011?file=Pocket+Sports+Design.dc.html).
Components in that project: `Char`, `Paddle`, `HandPhone`, `Qr`, `Scene`. Design system: Ensembl (cobalt/coral/sun on cream).

- `tokens/`: verbatim design-system tokens (colors, typography, effects, spacing, base).
- `SPEC.md`: a digest of every screen, state, game token, motion/sound rule and the 3D asset list, transcribed from the design file.
  The raw `.dc.html` files were not copied (they need the Claude Design runtime). Open the link above for the visual source of truth.

Visual conflicts: /design wins. Behavior conflicts: the build spec wins. Where they differ, `SPEC.md` notes it.
